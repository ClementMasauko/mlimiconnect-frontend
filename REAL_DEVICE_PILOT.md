# Affordable Android performance pilot

Run each release on at least three physical Android devices with 2-4 GB RAM and Android 10 or later. Use Chrome network throttling at 400 kbps download, 200 kbps upload and 400 ms RTT, then repeat on a real TNM and Airtel mobile connection.

Record device, OS, network, cold landing load, marketplace load, search interaction, listing creation with a 5 MB photograph, checkout, offline help, images-off bytes, compact-mode usability, crashes, peak memory and battery temperature. Acceptance targets: useful landing content within 5 seconds, marketplace interaction within 8 seconds, no crash, compressed uploads below 900 KB where possible, and no non-essential image request in images-off mode.

Automated build budgets run in CI. Physical-device results require a named tester, date and evidence; they cannot be truthfully generated by source code alone.
