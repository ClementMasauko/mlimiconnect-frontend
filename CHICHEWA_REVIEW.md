# Chichewa language review

The English and Chichewa catalogs have automated key parity checks. Before release, a fluent Chichewa reviewer must review every screen on a phone, record the reviewer and date, and approve agricultural terminology, respectful tone, plural forms, validation errors, dates, quantities, units, currency, and low-literacy clarity. Automated translation is not accepted as linguistic sign-off.
